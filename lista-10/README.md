## 📋 Requisitos Obrigatórios (O que será avaliado)

Para que a atividade seja validada, o seu projeto deve cumprir os seguintes pontos:

### 1. Estrutura de Pastas Correta
O projeto deve estar organizado conforme o material, separando adequadamente:
- Arquivos `.html` na raiz (ex: `index.html`).
- Pasta `/css` para os estilos.
- Pasta `/assets` para imagens, ícones ou fontes (se utilizar).

### 2. Organização Modular do CSS
- Criar o arquivo `variables.css` contendo as variáveis do projeto (dentro do seletor `:root` defina cores, tipografia e espaçamentos).
- Criar o arquivo `styles.css` (ou `main.css`) e usar a regra `@import url('variables.css');` no topo dele para importar as variáveis.

### 3. Uso Consciente das Unidades de Medida
Vocês devem aplicar as unidades aprendidas de forma estratégica:
- **`rem`**: Obrigatório usar para definir o tamanho das fontes.
- **`%`**: Obrigatório usar para definir a largura (`width`) de containers, blocos ou elementos flexíveis.
- **`vh` ou `vw`**: Obrigatório usar em pelo menos uma seção (exemplo: um banner inicial, um header ou um fundo que ocupe a tela inteira).
- **`px`**: Usar apenas onde faz sentido não escalar (ex: espessura de bordas, sombras ou dimensões exatas de pequenos ícones).
